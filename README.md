# Single Inheritance in C++

This project demonstrates the concept of **Single Inheritance** in C++.

## Description

Single inheritance is a type of inheritance in which one derived class inherits properties and functions from one base class.

### Structure

```text
Student (Base Class)
       ↓
Result (Derived Class)
```

## Concepts Used

* C++ Classes and Objects
* Base Class
* Derived Class
* Public Inheritance
* Member Functions

## File

`single_inheritance.cpp`

## Example

The program takes student details such as name, roll number, and marks, and displays the information using a derived class.
